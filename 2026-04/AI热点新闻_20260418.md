# AI热点新闻
> 更新日期：2026年04月18日

## 一、AI技术

1. **OpenAI 重磅升级 Codex：可操控电脑、多智能体并行** — 4月16日，OpenAI 对 Codex 进行了产品级重构，桌面版新增计算机使用能力（自主控制光标点击输入）、多智能体并行工作流、应用内浏览器、图像生成与长期记忆，可跨天跨周恢复任务，正面硬刚 Anthropic Claude Code。 [[1]](https://siliconangle.com/2026/04/16/openai-ratchets-codexs-agentic-capabilities-rival-claude-code/)

2. **OpenAI 发布首个生命科学专属模型 GPT-Rosalind** — 4月16日 OpenAI 正式推出 GPT-Rosalind，以 DNA 结构发现者 Rosalind Franklin 命名，针对生物化学与基因组学的多步科研任务。在 BixBench 生信基准登顶，RNA 序列预测超越 95% 人类专家；首批向 Amgen、Moderna 等企业开放研究预览。 [[2]](https://venturebeat.com/technology/openai-debuts-gpt-rosalind-a-new-limited-access-model-for-life-sciences-and-broader-codex-plugin-on-github)

3. **腾讯开源混元3D世界模型 2.0，一句话生成可编辑3D资产** — 4月16日腾讯正式发布并开源混元 3D 世界模型 HY-World 2.0。相比谷歌 Genie 3 仅能输出视频，HY-World 2.0 可直接生成 Mesh/3DGS/点云等可二次编辑的 3D 资产，无缝对接主流游戏引擎与具身仿真引擎，支持文本、图像、视频多模态输入。 [[3]](https://www.ithome.com/0/939/747.htm)

4. **Google 发布 Gemini 3.1 Flash TTS，原生支持70+语言多说话人对话** — 4月15日 Google 推出 Gemini 3.1 Flash TTS 预览版，通过自然语言音频标签控制语气与节奏，原生支持 70+ 种语言与多说话人对话生成，在多语种表现力与低延迟上刷新业内 TTS 基准。 [[4]](https://www.marktechpost.com/2026/04/15/google-ai-launches-gemini-3-1-flash-tts-a-new-benchmark-in-expressive-and-controllable-ai-voice/)

5. **DeepSeek V4 月底发布，首款全栈适配华为昇腾的万亿 MoE 模型** — 4月15日消息，DeepSeek V4 将于4月下旬正式发布并 Apache 2.0 开源，1 万亿参数 MoE 架构（每 token 激活 320-370B），100 万 token 上下文，完全基于华为昇腾 950PR 芯片训练与推理，英伟达 AMD 均未在预发布测试列表中。 [[5]](https://finance.sina.com.cn/wm/2026-04-15/doc-inhuqsme4656391.shtml)
